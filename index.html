Uninformed Search

Three ways to search for a goal

Uninformed search uses only the information given in a problem. It does not use a heuristic, or an estimate of the remaining distance to the goal. It is also called blind search.

Choose an algorithm to study its theory and follow a working example.

01 · LEVEL BY LEVEL

BFS

Breadth-First Search explores nearby nodes first. It uses a queue.

02 · ONE BRANCH AT A TIME

DFS

Depth-First Search goes deep along one branch, then backtracks. It uses a stack.

03 · LOWEST TOTAL COST FIRST

Uniform-Cost Search

UCS selects the node with the lowest path cost from the start. It uses a priority queue.

Underflow: trying to remove an item from an empty structure.
Overflow: trying to insert an item into a full, fixed-capacity structure. The new item is rejected; existing items stay unchanged.

Basic terms to remember

  • State: a situation in the problem, represented by a node.
  • Initial state: the state from which the search begins.
  • Action: a move from one state to another, represented by an edge.
  • Goal test: a check to decide whether the required state has been reached.
  • Frontier: discovered nodes waiting to be selected for expansion.
  • Expansion: generating or examining the neighbours of a node.
  • Path cost g(n): the sum of edge costs from the start to node n.
  • Solution path: the connected route from the start to the goal. It is not the same as the search order.

Complete means the method is guaranteed to find a solution if one exists, under its stated conditions. Optimal means it is guaranteed to find a solution with the lowest cost.
